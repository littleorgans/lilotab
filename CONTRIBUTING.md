# Contributing

Bug reports, feature requests, and change proposals are welcome as issues.

Development happens in a private repository. This public repository receives published snapshots only. We close pull requests without reading or reviewing the changes.

To propose a change, open an issue describing the problem, the intended result, and your patch idea.

If you paste code, state its licence and confirm that you have permission to share it. We may ask for a separate licence before using it.

`C-` and `T-` ids in code cite an internal specification.

Thank you for helping improve lilotab.
